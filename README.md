# Python Factorial Program 🐍

A beginner-friendly Python program to find the factorial of a number using a `for` loop.

## 📖 About the Project

This project demonstrates a basic mathematical operation using Python. It calculates the factorial of the number `5` by multiplying the integers from `1` to `5`.

## 🔍 Understanding Factorial

Factorial is the product of all positive integers from `1` to a given non-negative integer.

**Example:**

```text
5! = 5 × 4 × 3 × 2 × 1 = 120
```

## ✨ Key Highlights

- Easy-to-understand Python code.
- Uses a `for` loop for repeated multiplication.
- Stores the calculated result in a variable.
- Prints the final answer using the `print()` function.
