# Factorial Calculator 🐍

A simple Python program that calculates the factorial of a fixed number using an iterative `for` loop.

## 📌 Project Description

This project demonstrates a basic factorial calculation in Python.

The program initializes the number `n` with the value `5`, sets the factorial variable to `1`, and multiplies it by each integer from `1` through `n`. Finally, it prints the calculated factorial.

For example:

```text
5! = 5 × 4 × 3 × 2 × 1 = 120
```

## ✨ Features

- Simple and beginner-friendly Python program.
- Uses a `for` loop for iteration.
- Performs repeated multiplication to calculate the factorial.
- Displays the calculated result.
- Does not require external libraries.
